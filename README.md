# 物件と役割をランダムにする試作版

## アップロード

このZIPの11個のHTML（表紙1・物件9・最終1）を、同じ階層にアップロードしてください。画像、図面、CSS、JavaScriptは各HTMLに埋め込んであり、別ファイルのアップロードは不要です。

現在のサイトと別に試す場合は、公開元に例えば `trial` フォルダを作り、その中に11個のHTMLを置きます。そのフォルダの `index.html` が入口です。同じフォルダの既存 `index.html` や `survey.html` を上書きすると、既存サイトの入口・最終ページも試作版に変わります。

## ページ構成

|物件|実験装置|文章あり|文章なし|
|---|---|---|---|
|光を受けとめる白い部屋|dobashi-apparatus.html|dobashi-text.html|dobashi-plain.html|
|木の窓辺に残る時間|kiyosumi-apparatus.html|kiyosumi-text.html|kiyosumi-plain.html|
|西日にほどける部屋|nishiogikubo-apparatus.html|nishiogikubo-text.html|nishiogikubo-plain.html|

表紙は `index.html`、最終ページは `survey.html` です。

- 実験装置：販売価格を表示。紹介文は客観的な情報のみ。
- 文章あり：価格非表示。約1,000字の情緒的な紹介文を掲載。
- 文章なし：価格非表示。紹介文は客観的な情報のみ。

同じ物件の3条件で、写真5枚・間取り図・基本情報・詳細情報・物件名を共通にしています。パースと図面は既存版を使用し、作り直していません。条件名は対象者の画面上には表示していません。

実験装置の販売価格は、土橋3,480万円、清澄4,380万円、西荻北5,280万円という研究用の架空設定です。土橋・清澄の価格は今回新たに設定しています。市場査定ではありません。設定の一覧は `condition-settings.json` にあります。

## 選択と閲覧

1. 表紙の「次へ」で、3物件に3役割を重複なく割り当てます。
2. その3ページの閲覧順もランダムにします。
3. 各物件の「次へ」で選ばれた次のページへ進み、3件目のあと最終ページへ移動します。
4. 最終ページに、閲覧した順に3物件のサムネイルを表示します。サムネイルは、同じ物件・同じ役割のページを別タブで開きます。
5. 再閲覧ページの下部には「アンケートのご案内に戻る」ボタンを表示します。

役割割当て6通り × 閲覧順6通り = 36通りです。単純なランダム選択であり、複数の対象者間の人数が均等になるようには割り付けていません。

選択された組み合わせと順序をURLの `set` パラメータに保持します。再読み込みやブラウザの「戻る」でも同じ組み合わせです。表紙から新しく開始すると、改めて抽選します。Cookieやサーバー保存は使いません。

閲覧情報のない最終ページには、任意の物件リンクを表示せず、表紙への案内を表示します。各物件HTMLを直接開いた場合は内容を確認できますが、「次へ」の代わりに「表紙へ」を表示します。

## Googleフォームについて

「アンケートへ」は既存のGoogleフォーム回答用URLに接続しています。Googleフォーム自体は今回変更していません。既存フォームで文章あり・文章なしの対象物件名や戻りリンクが固定されている場合、今回のランダムな割当てと一致しないため、本番の回答収集前にフォームを調整してください。

この試作は、どの役割をどの物件に割り当てたかをGoogleフォーム回答へ自動記録する機能をまだ持ちません。フォーム側への割当て情報の記録・物件概要・戻りリンクの対応は、次の調整項目です。

## 確認済みの動作

36通りすべてで、物件と役割の重複がないこと、次ページへの移動、再閲覧からの復帰、最終ページのリンク対応を確認しています。同一物件の条件間で写真・図面・詳細情報が一致し、販売価格が実験装置条件だけに表示されることも確認しています。
